# Shuvo Portfolio — Ivory & Orange Edition

A six-page static HTML/CSS/JavaScript personal portfolio, ready for GitHub Pages.

## Changes in this edition
- One permanent light theme: main background **#fffcec**. The dark-mode UI, JavaScript, and saved theme preference are removed.
- Updated ivory, ink, warm orange and neutral surfaces for the hero, every inner page, forms, project cards and footer.
- Hero uses the **original unmodified** `assets/original-photo.jpg` in its full-width right-side placement. The soft blend is created with a **CSS gradient overlay**, not image manipulation.
- All links, AI-agent learning skills, four projects and `resume.pdf` are retained.

## Deploy to GitHub Pages
1. Extract this ZIP. Upload **all files and folders inside** the website folder to the **root of the `main` branch** in `https://github.com/mhshuvo1830/shuvo-portfolio` (or the folder configured in Settings → Pages).
2. Preserve the original relative paths, especially `assets/original-photo.jpg`, `styles.css`, `script.js`, and `resume.pdf`.
3. Commit, open the Actions tab, and verify that GitHub Pages deployment succeeds.
4. Open `https://mhshuvo1830.github.io/shuvo-portfolio/?v=cream-20261124` and hard-refresh.
5. Confirm navigation, project live demos, CV download, mobile menu and contact form. The contact form creates an email draft (not a server-side submission).
