# GitHub Pages deployment checklist

1. Backup the existing `shuvo-portfolio` repository.
2. Extract the ZIP; upload **its contents**, not an extra enclosing directory, to the publishing folder configured in **Settings → Pages**.
3. The main branch root should contain `index.html`, `about.html`, `skills.html`, `projects.html`, `research.html`, `contact.html`, `styles.css`, `script.js`, `resume.pdf`, and an `assets/` folder.
4. Commit. Wait for GitHub Actions to show a successful Pages deployment.
5. Visit `https://mhshuvo1830.github.io/shuvo-portfolio/?v=cream-20261124`; hard refresh.
6. Check that the theme icon is gone, original photo fades into ivory background, six pages open, CV downloads, project demos work, and contact form prepares an email draft.
7. Test Firefox and real phone manually.
